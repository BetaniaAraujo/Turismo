# Turismo

An informational website about tourist destinations in Portugal, built with HTML and CSS during the **EFA NS PRO — Software Development Technician** training program (IEFP).

## 🎯 Purpose

Practice structuring a multi-page website, applying semantic markup, content organization, and a form for user interaction.

## 🧩 Features

- Navigation across multiple pages, each dedicated to a different tourist destination
- Comment form for visitor interaction
- Responsive layout with HTML and CSS

## 📁 Repository structure

```
Turismo/
├── index.html          # Home page
├── [destination pages]     # One page per tourist destination
├── css/                 # Stylesheets
├── imagens/             # Visual assets for each destination
└── README.md
```

## 🛠️ Technologies

- HTML5
- CSS3

## ▶️ How to view

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/BetaniaAraujo/Turismo.git
cd Turismo
```

Then simply open `index.html` in your browser (or publish it via GitHub Pages for a live link).
